# 📦 Sistema de Controle de Estoque Automatizado - Excel

## 📌 Sobre o projeto

Planilha de controle de estoque desenvolvida para automatizar a gestão de materiais, integrando entradas e saídas com atualização automática do estoque. Este projeto foi desenvolvido como parte do meu portfólio para demonstrar habilidades em Excel, automação de planilhas e resolução de problemas reais de negócio.

> *"Não quero precisar entrar na planilha de estoque para dar baixa manualmente."*

## 🎯 Requisitos atendidos

- ✅ Cadastro de materiais com categorias e unidades de medida
- ✅ Controle automático de estoque (entradas e saídas)
- ✅ Alerta de estoque baixo e materiais zerados
- ✅ Cálculo automático da necessidade de reposição
- ✅ Lista dinâmica de materiais para compra
- ✅ Fórmulas protegidas para evitar alterações acidentais
- ✅ Filtros e organização para facilitar a navegação

## 🛠️ Funcionalidades principais

| Aba | O que faz |
| :--- | :--- |
| **CADASTRO** | Cadastro de materiais, categorias, unidades e estoque mínimo |
| **MOVIMENTACOES** | Registro diário de entradas e saídas (com validação de dados) |
| **ESTOQUE** | Cálculo automático do estoque atual, situação e necessidade de compra |

## 📊 O que foi utilizado

- **Excel** (Microsoft 365)
- **Fórmulas Avançadas:** PROCV, SOMASE.S, SE aninhado
- **Validação de Dados:** Listas suspensas para padronização
- **Proteção de Planilhas:** Bloqueio de fórmulas

## 🚀 Como usar

1. Baixe o arquivo `controle_estoque.xlsx`.
2. Preencha a aba **CADASTRO** com os materiais e estoque mínimo.
3. Lance as movimentações na aba **MOVIMENTACOES**.
4. A aba **ESTOQUE** será atualizada automaticamente.
5. Consulte a **lista de compras** na aba ESTOQUE (coluna "Lista de Compras").
